THE WRATH OF GONGGONG

Chinese Title: 共工之怒
Version: V0.2
Package refreshed: 25 September 2026
Engine: Unreal Engine 5.7.0
Platform: Windows 64-bit

LAUNCH

1. Extract the complete build folder before launching.
2. Run Gonggong.exe.
3. Keep the Engine and Gonggong folders beside Gonggong.exe. Do not move the launcher out of the extracted folder.
4. If Windows reports a missing Microsoft Visual C++ runtime, run Engine/Extras/Redist/en-us/vc_redist.x64.exe, then try launching again.

CONTROLS

Movement: WASD
Camera: Mouse
Jump: Space
Attack: Left Mouse Button (when not placing ice)
Interact: E
Create Ice: After acquiring the ice relic, press Q to select it, move the mouse to choose a placement position, then press the Left Mouse Button to place ice.
Skills: 1 / 2 / 3
Use Dungeon Item: R
Exit: Alt+F4

There is no dedicated dodge action, pause function or in-game exit menu.

START CONDITION

The player begins in a small village under attack by hostile spirits.

COMPLETION CONDITION

The playable experience ends after defeating the final Boss, Gonggong, and reaching the ending sequence.

TECHNICAL REQUIREMENTS

- Windows 64-bit.
- DirectX 12 and Shader Model 6 capable graphics hardware.
- Run the game from a fully extracted folder.

PROTOTYPE STATUS

This is a portfolio prototype. V0.2 includes changes following three external V0.1 playtests. Developer regression checks for those changes were recorded on 7 September 2026; external V0.2 retesting remains pending.

The 25 September package refresh includes the boss dialogue spelling correction from GLOD to GOLD. It retains the V0.2 version number.
